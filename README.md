# Chatbot

Dieses Projekt enthält ein einfaches OpenAI-Chatbot-Skript.

## Setup

1. Kopiere `.env.example` zu `.env` und ersetze den Platzhalter durch deinen echten API-Key.
2. Installiere die Abhängigkeiten mit `pip install openai`.
3. Starte das Programm mit `python main.py`.

## Sicherheitshinweis

Die Datei `.env` enthält Secrets und sollte niemals in GitHub gepusht werden.
